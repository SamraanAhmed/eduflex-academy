## 💻 Git & GitHub Workflow for Students

```bash
# 1. Clone the repository
git clone https://github.com/your-org/eduflex-academy.git
cd eduflex-academy

# 2. Switch to dev branch and pull updates
git checkout dev
git pull origin dev

# 3. Create your feature branch
git checkout -b feature/your-name-pillar

# 4. Check status & commit daily work
git status
git add .
git commit -m "feat: added ethical hacking course syllabus for Day 3"

# 5. Push feature branch to GitHub
git push origin feature/your-name-pillar

# 6. Submit Pull Request on GitHub to 'dev' branch
```
